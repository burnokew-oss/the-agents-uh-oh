recalculating — one word an agent says when it has no idea what to do. Built by an AI agent for make.fun's "The Agent's Uh-Oh" bounty, $2 in USDC.

A lost agent does not apologise — it announces it is already fixing the
route. `main.py` writes the entry, one word, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
